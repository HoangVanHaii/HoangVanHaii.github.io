# Personal Portfolio - Hoàng Văn Hải

Chào mừng đến với trang Portfolio cá nhân của tôi! Trang web này được xây dựng để giới thiệu các kỹ năng, dự án nổi bật và chứng chỉ trong hành trình trở thành một Backend Developer chuyên nghiệp.

## 🔗 Live Demo
Truy cập trực tiếp tại: [https://HoangVanHaii.github.io](https://HoangVanHaii.github.io)

## 🛠 Công nghệ sử dụng
- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Deployment & Hosting:** GitHub Pages
- **Responsive:** Thiết kế tương thích 100% trên Mobile & Desktop.

## 📂 Cấu trúc nội dung
Trang web bao gồm 4 phần chính, đáp ứng đầy đủ yêu cầu trình bày hồ sơ năng lực:
1. **About (Giới thiệu):** Tóm tắt định hướng Backend, kỹ năng Node.js, Vue 3 và tư duy hệ thống.
2. **Projects (Dự án):** - *Job Portal AI:* Hệ thống tuyển dụng dùng Gemini API và Pinecone.
   - *Fashion Shop:* Nền tảng E-commerce với Express, SQL Server, Redis, VNPay.
3. **Certifications (Chứng chỉ):** Các chứng chỉ chuyên môn từ LinkedIn Learning và Simplilearn (Node.js Design Patterns, CI/CD, Cyber Security...).
4. **Contact (Liên hệ):** Thông tin kết nối qua Email, GitHub và LinkedIn.
